#  Library Management System

A command-line interface (CLI) application built with Python to efficiently manage library operations, book inventories, and user interactions using Object-Oriented Programming (OOP) principles.

##  Features
* **Book Management:** Add, search, and view available books in the library.
* **User Management:** Register members and track borrowing histories.
* **Borrow & Return System:** Process book checkouts and returns seamlessly.
* **Error Handling:** Graceful handling of invalid inputs and missing inventory records.

##  Tech Stack & Concepts
* **Language:** Python 3
* **Concepts:** Object-Oriented Programming (OOP), Data Structures (Lists, Dictionaries), File/Data Handling
